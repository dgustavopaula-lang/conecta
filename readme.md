# Conecta | GPS.dev 🚀

**Vitrine de projetos, aplicativos e mini-softwares do ecossistema GPS.dev.**

O **Conecta** reúne informações e caminhos de acesso a soluções digitais desenvolvidas por Gustavo Santos. O objetivo é facilitar a apresentação dos projetos, a descoberta de aplicações e a organização de uma oferta de tecnologia útil para pequenos negócios e outras áreas.

> O Conecta é uma vitrine. A **NexoTerraCore/API Central** é o núcleo arquitetural do ecossistema; integrações e funcionalidades devem ser verificadas individualmente antes de serem apresentadas como operacionais.

- **Segurança e privacidade:** não publicar credenciais, dados privados ou informações sensíveis.

- **Acessibilidade:** tornar produtos e informações compreensíveis e úteis.
